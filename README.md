"The Kintsugi Moon" — a lone samurai in silhouette on a cliff edge, facing an
enormous full moon cracked like porcelain and mended with glowing gold, in the
kintsugi tradition that broken things come back more beautiful. Crimson maple
leaves ride the night wind. Bold ukiyo-e-inspired illustration in indigo, gold
and crimson; the artwork ships as `entry.png` (JPEG bytes, 683×1024, 264 KB)
and the program copies it, unchanged, to the output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
